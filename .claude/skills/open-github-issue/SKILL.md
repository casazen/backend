# Open GitHub Issue

Procedure for creating structured GitHub issues via `gh` CLI.

## Step 1 — Check authentication

```bash
gh auth status || { echo "ERROR: Run 'gh auth login'"; exit 1; }
```

## Step 2 — Check for duplicates

```bash
gh issue list --search "<keyword1> <keyword2>" --state open --json number,title
```

If a similar issue exists → add a comment instead of creating a duplicate.

## Step 3 — Ensure labels exist

```bash
gh label create "regulatory"       --description "Regulatory requirement"  --color "d93f0b" 2>/dev/null || true
gh label create "compliance"       --description "Compliance gap"          --color "fbca04" 2>/dev/null || true
gh label create "priority:critical" --color "b60205" 2>/dev/null || true
gh label create "priority:high"    --color "d93f0b" 2>/dev/null || true
gh label create "priority:medium"  --color "e4e669" 2>/dev/null || true
gh label create "priority:low"     --color "0e8a16" 2>/dev/null || true
gh label create "contract-sync"    --description "FE/BE contract misalignment" --color "0075ca" 2>/dev/null || true
```

## Step 4 — Create issue

```bash
ISSUE_URL=$(gh issue create \
  --repo casazen/backend \
  --title "[COMPLIANCE] <concise gap title>" \
  --label "regulatory,compliance,priority:critical,scope:backend,effort:M" \
  --milestone "<regulatory-deadline>" \
  --body "$(cat <<'EOF'
## User Story
As a **[role]**, I want **[action]**, so that **[benefit]**.

## Regulatory Context
- **Reference**: [law/decree]
- **Effective date**: [date]
- **Penalties**: [description]

## Current State
[What exists in the codebase]

## Implementation Requirements
- [ ] Backend: [details]
- [ ] Frontend: [details]
- [ ] Testing: [details]
- [ ] Documentation: [details]

## Acceptance Criteria
- [ ] GIVEN [precondition], WHEN [action], THEN [expected result]

## References
- [Regulatory source URL]

---
_Generated by CasaZen Regulatory Intelligence_
EOF
)")
echo "Created: $ISSUE_URL"
```

## Step 5 — Add deadline comment (for CRITICAL issues)

```bash
ISSUE_NUMBER=$(echo "$ISSUE_URL" | grep -o '[0-9]*$')
gh issue comment "$ISSUE_NUMBER" \
  --body "⚠️ **Regulatory deadline**: [date]. Penalties from [date] if not compliant."
```

## Step 6 — Cross-link (full-stack features)

```bash
# Add FE reference to BE issue
gh issue comment "$BACKEND_ISSUE_NUM" --body "🔗 **Frontend**: casazen/frontend#$FRONTEND_ISSUE_NUM"

# Add BE reference to FE issue
gh issue comment "$FRONTEND_ISSUE_NUM" --repo casazen/frontend \
  --body "🔗 **Backend**: casazen/backend#$BACKEND_ISSUE_NUM"
```

## Limits

- Max 10 issues per run (avoid flooding backlog)
- CRITICAL first, then HIGH, MEDIUM, LOW
- Always check duplicates before creating
- Never include credentials or PII in issue body

## Issue title conventions

- `[COMPLIANCE] <description>` — regulatory gap
- `[CONTRACT] <description>` — FE/BE misalignment
- `[FEATURE] <description>` — product feature
- `[BUG] <description>` — bug report
