# Git Workflow

## Branches
- Features: `feature/<name>` | Fixes: `fix/<name>` | Hotfixes: `hotfix/<name>`

## Commits
- Format: Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`)
- **NEVER** include "Co-Authored-By: Claude" signature

## PRs
- Must pass CI, include tests, link issue (`Closes #123`), screenshots for UI changes
