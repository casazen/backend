# Contesto del repository frontend

Per struttura, convenzioni e avvio leggere la [documentazione mantenuta nel frontend](https://github.com/casazen/frontend/blob/develop/docs/README.md) e il suo [README](https://github.com/casazen/frontend/blob/develop/README.md).

Il frontend usa React 19, TypeScript, Vite 8 e TanStack Query 5. Le pagine applicative sono organizzate in aree e protette da autenticazione, onboarding e guard del workspace. Il contratto effettivo è nel codice del repository frontend e nelle API, non in una copia dell’albero route nel backend.

Questo file mantiene l’indirizzo precedentemente usato dalle istruzioni di repository. Per il backend continuare da [PROJECT.md](PROJECT.md); per i flussi operativi usare l’[indice runbook](runbooks/index.md).
